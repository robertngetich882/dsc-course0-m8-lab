# Aviation Accident Analysis
Aviation Accident Data Analysis

Project Overview

This project analyzes aviation accident data to understand aircraft safety, passenger injuries, and aircraft damage. The analysis focuses on identifying patterns in fatal and serious injuries and examining factors that may be associated with aircraft damage and injury outcomes.

Objectives

The main objectives of this project are to:

- Clean and prepare the aviation accident dataset.
- Analyze fatal and serious passenger injuries.
- Compare safety outcomes between small and large aircraft.
- Identify aircraft makes and models with lower injury rates.
- Analyze aircraft destruction rates by aircraft make.
- Investigate how weather conditions and engine types affect aircraft damage and injury.
- Use visualizations to communicate the findings.

Data Analysis

The analysis includes:

1. Data cleaning and handling missing values.
2. Creation of a fatal/serious injury fraction.
3. Classification of aircraft into small and large planes using a passenger threshold of 20.
4. Analysis of injury rates by aircraft make and model.
5. Analysis of aircraft destruction rates.
6. Distributional analysis using violin plots.
7. Analysis of weather conditions and engine types.

Visualizations

The project uses several visualizations, including:

- Bar charts
- Violin plots
- Distribution plots
- Comparisons of small and large aircraft
- Injury and aircraft destruction rate comparisons

Key Findings

The analysis shows that safety outcomes vary between aircraft makes, models, and plane types. Some aircraft have lower fatal/serious injury fractions and lower destruction rates than others. Weather conditions and engine types also show differences in injury outcomes.

The findings should be interpreted carefully because the number of observations differs between aircraft makes and categories.

Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Conclusion

This analysis provides an overview of aircraft safety patterns using historical accident data. The results can help identify aircraft types and operating conditions associated with lower injury and damage rates. However, the analysis shows associations rather than proving that a particular factor directly causes an accident outcome.
